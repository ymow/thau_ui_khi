# OpenSpec

This directory contains the specifications for this project using the OpenSpec framework.

## Structure

- **specs/** - Current source-of-truth specifications
- **changes/** - Proposed specification updates and changes

## Workflow

1. **Draft Changes**: Create a new change proposal in `changes/`
2. **Review**: Collaborate with AI assistants to refine specifications
3. **Implement**: Follow the task lists in change proposals
4. **Archive**: Merge approved changes back into `specs/`

## Getting Started

To propose a new change:
```bash
openspec change <feature-name>
```

To work with AI assistants, use the slash commands or reference the AGENTS.md file.
